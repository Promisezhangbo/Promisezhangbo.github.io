# Oxlint 从 0 到 1

**定位：** Oxc 家族的 **Rust lint**，实现最常用的 ESLint 规则，快 10–100 倍。本仓库：`oxlint ^1.57`，各 `apps/*/.oxlintrc.json`，`pnpm lint` 走 turbo。

官方：[oxc.rs/docs/guide/usage/linter](https://oxc.rs/docs/guide/usage/linter.html)
