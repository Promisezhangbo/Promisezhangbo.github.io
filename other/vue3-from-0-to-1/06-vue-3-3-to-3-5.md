# 6. Vue 3.3 – 3.5

新项目默认按 **3.5** 学这些即可。

## 6.1 3.3（2023-05）DX / TS

- **`defineOptions({ name, inheritAttrs })`**：setup 里补 Options。
- **`defineSlots<{ default(props: { row: Row }): any }>()`**：插槽类型，运行时 no-op。
- **导入类型做 `defineProps<Props>()`**（可从 `types.ts` import）。
- **泛型组件：** `<script setup lang="ts" generic="T extends string">`。
- `toValue()`：统一解开 ref/getter。

## 6.2 3.4（2023-12）

### `defineModel` 稳定

```vue
<script setup>
const model = defineModel<string>({ required: true });
</script>
<template>
  <input v-model="model" />
</template>
```

代替手写 `modelValue` + `emit('update:modelValue')`。多个：`defineModel('title')`。

### 同名简写

```vue
<!-- 3.4+ 变量名和 prop 同名 -->
<img :id :src :alt>
<!-- 以前必须 :id="id" -->
```

解析器重写，编译更快；一般无代码变化。

## 6.3 3.5（2024-09）

### 响应式 props 解构（稳定）

```vue
<script setup>
const { title, size = 16 } = defineProps<{ title: string; size?: number }>();
watch(() => title, ...); // 3.5 里 title 仍是响应的（编译成 props.title）
</script>
```

3.4 及以前解构会丢掉响应，必须 `props.title` 或 `toRefs`。现在可以像普通变量写，**但要理解这是编译器把戏**，不是真的把 prop 变成了 ref。

### `useTemplateRef('input')` ≥3.5

```vue
<script setup>
import { useTemplateRef, onMounted } from 'vue';
const input = useTemplateRef('input');
onMounted(() => input.value?.focus());
</script>
<template>
  <input ref="input" />
</template>
```

以前要 `const input = ref(null)` 且 **变量名和模板 ref 字符串相同**。新 API 显式绑定，避免改名漏改。

### `useId()` ≥3.5

SSR 安全的唯一 id，对无障碍 `for`/`aria`。对标 React 18 `useId`。

### `onWatcherCleanup` ≥3.5

在 `watch`/`watchEffect` 回调里登记清理：下一次执行或停止监听时跑。适合 abort fetch。

### 其它

响应式系统内存/触发更准；SSR 水合改进。对应用代码通常无感。

## 6.4 还不需要追的

- **Reactivity Transform**（`$ref` 免 `.value`）：实验过，**已放弃**，不要在新代码用。
- Vue Vapor / 无虚拟 DOM：研究中，未当默认运行时。
