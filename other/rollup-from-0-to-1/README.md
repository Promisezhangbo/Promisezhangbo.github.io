# Rollup 从 0 到 1

**定位：** 以 **ESM 库** 见长的打包器：输出干净、tree-shaking 一流。应用侧历史上被 webpack/Vite 抢走；Vite 2–7 的生产打包 **就是 Rollup**。Vite 8 改用 Rolldown（API 刻意兼容 Rollup）。

官方：[rollupjs.org](https://rollupjs.org/)
