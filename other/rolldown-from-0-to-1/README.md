# Rolldown 从 0 到 1

**定位：** 用 Rust 写的打包器，**插件 API 对齐 Rollup**，速度接近 esbuild。VoidZero / Vite 团队主导。Vite **8 默认生产打包 + 依赖预构建** 都是它。本仓库 `build.rolldownOptions` 就是在配它。

官方：[rolldown.rs](https://rolldown.rs/)
