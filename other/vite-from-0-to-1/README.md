# Vite 从 0 到 1

**定位：** 前端开发服务器 + 生产打包的胶水层。开发时用原生 ESM 几乎不打包源码；生产再打包。本仓库：**Vite ^8**，生产/依赖预构建走 **Rolldown**，转换走 **Oxc**（不再默认 esbuild+Rollup）。

官方：[vite.dev](https://vite.dev/)
