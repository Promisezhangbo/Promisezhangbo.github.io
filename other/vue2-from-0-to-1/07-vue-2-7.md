# 7. Vue 2.7：收官与 Composition API 回移植

**版本：≥2.7.0（2022-07）。** Vue 2 最后一个功能版本，为了让存量项目能用 3 的写法做过渡。

## 7.1 内置了什么

- Composition API：`ref` `reactive` `computed` `watch` `watchEffect` `onMounted` … 从 `'vue'` 引，不必再装 `@vue/composition-api`
- SFC `<script setup>`
- CSS `v-bind(color)`
- 更好的 TS 类型（仍不如 3.3+）

若项目已在用 `@vue/composition-api`：升 2.7 后改从 `vue` 导入，卸插件。

## 7.2 和 Vue 3 **不一样** 的地方（重要）

2.7 的 `ref`/`reactive` 仍走 **defineProperty**：

- `reactive(obj) === obj`（3 是新 Proxy，`===` 为 false）
- 新增字段、数组下标赋值 **照样不触发**，还要 `$set`
- `readonly` 对数组/新字段能力弱
- **没有** `createApp`（全局 Vue 还是单例）
- `<script setup>` **没有** 顶层 `await`
- 模板表达式 **不能** 写 TS
- 没有 Teleport / Fragment / 真正的 Suspense（2.7 不移植这些）

所以：2.7 让你 **提前把逻辑拆成 composable**，并不能当成已经升 3。

## 7.3 `<script setup>` 在 2.7

```vue
<script setup>
import { ref } from 'vue';
const n = ref(0);
function inc() { n.value++; }
const props = defineProps({ title: String });
const emit = defineEmits(['change']);
</script>
```

顶层绑定自动暴露给模板。`defineProps`/`defineEmits`/`defineExpose` 可用。没有 3.3 的 `defineOptions`/`defineSlots`，没有 3.4 `defineModel`。

## 7.4 EOL 之后还用 2 吗

官方不再常规修。能升则升 3；短期必须留 2：钉死 **2.7.16+** 补丁、不要新功能写在 2 上、新模块按 composable 写方便以后迁。
